## 工具边界

`tvctl.py` 原有恢复与连接逻辑有离线设备模拟测试；通用脚本没有在最终正常的电视上重新执行恢复演练。新增 `policy_lists.py` 仅提供只读备份/复核和离线计划，没有设备写入功能；其测试也不连接电视。

最终离线验收结果：

- Python 3.12 共 41 项测试，40 项通过，1 项因 Windows 无创建真实符号链接权限而跳过；模拟符号链接检查通过。
- Bash 语法、CLI 帮助与无执行参数的恢复预览通过。
- 33 份 Markdown 的本地文件链接、锚点、代码块和双语页面配对检查通过。
- 41 个公开源文件通过隐私模式与 UTF-8 无 BOM / LF 检查；另生成 SHA256SUMS。ZIP 共 42 个文件，完整性与校验值通过，不包含缓存和私有记录。

本轮修正了一项依赖 Python 解析器递归行为的测试：深层 JSON 必须被解析器或快照 schema 安全拒绝，不要求所有 Python 版本使用同一句报错。新增相似版本、不同 BuildTime 及自定义后缀固件的拒绝测试。

本轮发现并修复了以下问题，独立审阅者已复核四项修订：

| 问题 | 修订 |
| --- | --- |
| 手动 ADB 连续命令在 root 失败后仍可能进入普通 shell | 改用有界工具作为主路径；手动排查分步设置成功门槛 |
