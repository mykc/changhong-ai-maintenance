# 维护记录模板

[English](en/maintenance-record-template.md) · [首页](../README.md)

复制到 `.local/` 后填写。发布时另写脱敏摘要，不直接公开现场记录。

## 请求和授权

- 日期、型号、完整固件、SDK：
- 用户希望实现的行为：
- 已授权动作、禁止动作及是否允许重启：
- 预计影响和恢复方法：

## 修改前

- 当前维护通道、身份和设备核验结果：
- 电脑备份位置：
- 原文件字节、SHA-256、所有者、权限、大小和修改时间：
- APK 来源、包名、版本、签名和现有安装：
- 原桌面、相关权限及运行状态：

## 执行与验证

- 预期差异与实际差异：
- 写前是否确认原文件未变：
- 写后字节、权限和系统实际行为：
- 安装/恢复命令的明确成功结果：
- 用户现场反馈原话：
- 未测试项目：

## 收尾与恢复

- 临时文件和安装包清理结果：
- 保留的电脑备份：
- 当前 ADB/SSH 状态及自启边界：
- 恢复步骤及必须保留的其他新变化：
- 从公开摘要中移除的个人信息、日志和截图：
